📖 Cara Top Up (30 detik)

  1. Buka Top Up Game, pilih game.
  2. Masukkan User ID + Server — sama persis seperti di profil game.
  3. Nickname muncul otomatis → yakin nama akun Anda benar sebelum bayar.
  4. Pilih nominal & metode bayar, selesaikan pembayaran sebelum timer habis.
  5. Item masuk 3–30 detik; simpan invoice SP-… untuk klaim garansi.

💡 Tips: screenshot ID di dalam game — beberapa game punya User ID terpisah dari Nickname.

🛡️ Garansi & Refund

  • Item tidak masuk >15 menit (bukan salah ID) → resend atau refund 100% maks 1×24 jam.

  • Salah input ID oleh pembeli: kami bantu ajukan banding ke publisher (tidak dijamin).
  • Chargeback/penyalahgunaan → pemblokiran permanen + blacklist.
